# Quick replies

A quick-reply trigger appears among the composer's activity buttons. Open it to pick a saved reply, or switch to the manage view to add, edit, and delete entries.

Replies are stored in the current browser's local storage, so they stay on this device and profile and never leave the page. Content can be plain text or include skill references such as `@dsh-doc`; choosing an entry inserts it at the current cursor position through the composer's revision-guarded insertion API.
